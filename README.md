# GTA 6 Interactive Map

Mapa interativo comunitário para organizar pontos de interesse de GTA 6.

## Estado atual
Estrutura inicial do projeto. O catálogo começa vazio: nenhum local será inventado ou publicado sem fonte/evidência.

## Categorias planejadas
- Armas e equipamentos
- Veículos raros/de luxo
- Dinheiro e tesouros
- Segredos e locais especiais
- Missões e atividades

## Status de evidência
- `confirmado`: evidência confiável disponível.
- `relatado`: informação ainda não confirmada.
- `em-investigacao`: precisa de mais evidências.

## Publicação com GitHub Pages
1. Abra **Settings → Pages**.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
4. Endereço esperado: https://dantasjavas.github.io/gta6-interactive-map1/

## Atualizações
O GitHub Actions poderá validar a estrutura do catálogo a cada 6 horas. Isso não descobre automaticamente novos locais no jogo; novos pontos precisam de fonte/evidência.

## Progresso
As marcações de encontrados ficam salvas neste navegador. A sincronização entre iPhone e computador ainda não está implementada.
